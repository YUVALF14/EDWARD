# Hybrid Life Atlas 8.0 — Statecraft Edition

A standalone Hebrew-language, right-to-left browser RPG about an open-ended life across entrepreneurship, community leadership, international relations and fictional politics.

## Play

1. Open [index.html](./index.html) in a browser (or download it and open locally).
2. Choose a starting age and city.
3. Make your first decision, explore businesses, parties, elections and public office.
4. Advance years, build coalitions, govern or return to other walks of life.

No build step or external dependencies are required.

## Features

- Fictional national and party politics, election results, coalitions and opposition
- Parliamentary, government and leadership pathways
- Dynamic age progression and an open-ended biographical narrative
- Business, community, policy and creative careers alongside political roles
- Local browser saves where supported, and JSON backup/import
- Responsive interface with RTL support

## Important notes

All parties, event outcomes and simulated election results are fictional. Political institutions and election timing are simplified for gameplay; this is **not** a prediction of real elections or lifespan.

This project is stored on a dedicated branch to avoid changing the existing EDWARD game's default branch. The playable file is `hybrid-life-atlas/index.html`.
